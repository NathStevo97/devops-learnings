# DevOps Learning and Research

Repository to house personal notes developed during various technology certification courses, challenges, etc; consolidated to one repo for ease of management.

## Tech Stack

- `mkdocs`
- `markdown`
- `github actions`
- `python` (Utility Scripts)

## Getting Started

### Linux

- Initialise a venv: `python3 -m venv .venv`
- Activate it: `source .venv/bin/activate`
- Install requirements: `pip install -r requirements.txt`
- Deactivate when Done: `deactivate`

- Deploy: `mkdocs serve`
